## What the newer evidence changes

- V3a improved the DenseNet judge's real melanoma recall, but its synthetic melanoma agreement was only 15.2%; 84.8% of synthetic melanoma was still read as nv. J1, an independent DINOv2 probe, failed its prespecified audit and was excluded. Neither should be silently accepted as a class-fidelity judge.
- A proxy-level matched-size study put v1's selected 616 images inside the distribution of random 616-image draws. That result is diagnostic; a full Stage 4 C-versus-D result is still missing.
- The quantity curve E4 is fully planned for 60 cells and passed a dry run. No complete E4 measurement or verdict is present in the local artifacts audited here. A count `q*` must not be claimed yet.
- The proposed equal-weight v2 composite is marked **NOT APPROVED** in `docs/ham10000_asism_v2_final_protocol.md` because it replaces the learned ranking claim with a hand-built baseline. It is useful as an explicitly named baseline, but cannot be reported as the learned ASISM condition C without a change of thesis scope.

## Work required to retain the original learned contribution

1. Freeze a new utility-supervision design before running it: target metric, fixed-size subset construction, repeat schedule, image coverage, independent validation subsets and a maximum GPU budget. The 2026-09-24 redesign document is a starting design, not a successful experiment. Its cheap proxy must first demonstrate reliability **and** agreement with the frozen Stage 4 recipe.
2. Run a CPU capacity check against a known set-utility function and a simple baseline. Mean pooling cannot encode subset count, so a size-aware model is necessary if training subsets have different sizes. If all training subsets have one size, quantity must be learned separately and the network's contribution must be described as ranking at that size.
3. Train the ranker only after utility labels pass the frozen reliability and validity gates. Evaluate it against independent measured subsets and against similarity-only and equal-weight baselines. Teacher imitation alone is insufficient.
4. Validate the threshold network out of class or across independently measured contexts. A network fitted to seven class-specific targets cannot support a general adaptive-learning claim without that check. Run E4 to measure the quantity effect; its verdict does not by itself validate the threshold network.
5. Freeze C and a per-class-count-matched random D before Stage 4. Train A/B/C/D with the same classifier recipe and multiple seeds. Report both balanced accuracy and macro AUROC, with uncertainty from training seeds as well as lesions.
6. Set the v2 test-set policy with the supervisor before another protected evaluation. If the already viewed split is reused, label the result a follow-up informed by v1; do not call it an untouched confirmatory test.
